Fysisk model og ligninger

FLRW: Den normaliserede model anvender H² = a⁻³⁽¹⁺ʷ⁾ − a⁻⁶, og accelerationen ä = −(1+3w)a⁻²⁻³ʷ/2 + 2a⁻⁵. Fluidet antages homogent, isotropt og med bevaret partikelantal. Spinkorrektionen skalerer som a⁻⁶. Den accelererede e-fold varighed er Nₐ꜀꜀ = ln[4/(1+3w)]/[3(1−w)] for 0≤w<1. N er ikke automatisk inflation.

KS: ds² = −dt² + X²dr² + Y²dΩ². I vores reducerede model: (Ẏ²+1)/Y² + 2ẊẎ/(XY) = ρ − S, 2Ÿ/Y + (Ẏ²+1)/Y² = −(wρ−S) og Ẍ/X + Ÿ/Y + ẊẎ/(XY) = −(wρ−S). Vi anvender ρ=ρ₀(XY²)⁻⁽¹⁺ʷ⁾ og S=S₀(XY²)⁻². ρ₀ bestemmes af startconstrainten. Disse approksimationer beskriver ikke fuld spinorientering, spin-gradienter eller en realistisk Kerr-geometri.

Basis: Bréchet m.fl. (Weyssenhoff-fluid), Hashemi m.fl. (FLRW-kollaps) samt Popławski (KS og torsion). Denne app er en udforskning af specificerede reducerede ligninger, ikke et bevis for et babyunivers.
